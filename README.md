# 사장님 데이터 비서

공공데이터로 보는 우리 동네 상권 · 세금 일정 · 예상 세금 계산 (세정회계법인 서동희 회계사)

- 앱: GitHub Pages로 제공. 방문자는 `data/` 폴더의 파일만 읽고 공공 API를 직접 호출하지 않습니다.
- 데이터 갱신(매월 1회, 관리자 PC): `python export.py` → `git add data && git commit -m "YYYY-MM 데이터" && git push`
- API 키는 이 저장소에 없습니다(관리자 PC의 `.env`).
- 예상 세금 계산 검증: `node tax_test.js`
